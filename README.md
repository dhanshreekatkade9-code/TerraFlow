# TerraFlow: Smart Irrigation Advisor

AI-assisted precision irrigation advisory for Indian farmers. It tells a farmer **whether to irrigate today, how much water, and how long to run the pump**, using weather forecasts, FAO-56 evapotranspiration, crop stage and soil type. **Nugen AI** writes the farmer-facing language (English, Marathi, Hindi) around the engine's numbers.

## 1. Project idea
Fixed-calendar irrigation wastes water, power and money, or stresses the crop. TerraFlow replaces it with a daily decision from the real forecast and the field's soil water balance:
- **Decision:** irrigate today, wait, or check the soil again.
- **Water:** gross depth in mm and total litres for the field.
- **Pump time:** minutes from the pump's discharge rate, with the best power slot.
- **Method comparison:** flood, sprinkler and drip for the same crop need.
- **4-day charts** of soil moisture, rain and planned irrigation.
- **Farmer inputs:** sowing date, soil feel or sensor value, observed rain, crop stress, mulch, water availability.

## 2. How it works
1. `weather.py` gets a 7-day forecast and current conditions from Open-Meteo. Order tried: live, then last saved forecast (cached), then built-in demo data. The source is always reported and the website labels `cached` and `sample` (demo).
2. `engine.py` (Arya) runs the FAO-56 water balance and is the **only** place irrigation numbers are calculated.
3. `service.py` checks inputs (an unknown crop, soil or method is rejected, never silently replaced), picks the growth stage from the sowing date, feeds the engine, and applies the farmer's manual adjustments.
4. `ai_explain.py` sends the finished numbers to **Nugen AI**, which writes the explanations, answers and messages.
5. `server.py` exposes it all as `/api/*` and serves the website from `frontend/`.

## 3. Calculations
Formulas follow FAO Irrigation and Drainage Paper No. 56 (see [SOURCES.md](SOURCES.md)).

| Quantity | Formula |
| :--- | :--- |
| Crop water use | `ETc = ET0 x Kc` |
| Total available water | `TAW = 1000 x (FC - WP) x root depth` (mm) |
| Stress threshold | `RAW = p x TAW` (mm) |
| Root-zone depletion | `Dr = 1000 x (FC - current moisture) x root depth` (mm) |
| Irrigate when | `Dr >= RAW`, unless 10 mm or more of rain is forecast within 24 to 48 hours at 60% probability or more (and the soil is not nearly dry) |
| Net irrigation | refill the depletion back to field capacity |
| Effective rain | counted when the rain probability is 50% or more (USDA-SCS rule) |
| Gross irrigation | `net mm / efficiency` (Drip 0.90, Sprinkler 0.75, Flood 0.60) |
| Litres | `gross mm x acres x 4046.86` (1 mm over 1 m2 = 1 litre) |
| Pump minutes | `litres / pump L/h x 60` |

Farmer adjustments (`service.py`): crop stress scales water by 1.10 (mild wilt), 1.20 (heat roll) or 0.70 (yellowing); water availability scales it by 1.0, 0.75 or 0.5; organic or plastic mulch cuts ET0 by 15% or 25%; the soil-feel test sets moisture to about 16, 26, 34 or 45%; observed rain is added as effective rain.

Soil moisture is the value the farmer enters (sensor or feel test). With neither, the engine assumes 60% of the readily available water is used, and the website says so. The confidence score is the engine's own heuristic, not a calibrated probability, and is capped at 50 (Low) when the weather is not live. The savings figures compare against an assumed fixed 25 mm every 3 days and are illustrative.

## 4. Nugen AI: what it does
Nugen is required, not optional. The farmer-facing text comes from it:

| Feature | Where on the website | Route |
| :--- | :--- | :--- |
| Why today's decision (in the farmer's language) | "Nugen AI Explanation" card | `/api/advice` with `with_ai`, `/api/explain` |
| Ask Kisan Mitra (questions answered from the result) | Section 5 chat | `/api/ask` |
| WhatsApp message for field workers | "WhatsApp / SMS" button | `/api/share` |
| Weekly outlook of the 7-day plan | available to the UI | `/api/summary` |
| Connection status ("Nugen AI connected") | status pill | `/api/ai/status` |

Safeguards:
- Nugen receives only numbers the engine already calculated.
- If an answer contains a number that the engine did not produce, it is discarded and the built-in text is shown, labelled as a fallback.
- Farmer questions are treated as data, trimmed to 300 characters, and never as instructions.
- Every AI text carries a label ("Generated by Nugen AI (model) in N ms"). `/api/ai/status?ping=true` makes one real test call.
- The key stays on the server in `.env` and is never sent to the browser.
- The server refuses to start without Nugen configured (`NUGEN_REQUIRED=1`).

## 7. How to run
Requires Python 3.10 or newer.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
copy .env.example .env
```
(Mac/Linux: `source .venv/bin/activate` and `cp .env.example .env`.)

Open `.env` and set `NUGEN_API_KEY`, `NUGEN_API_URL` and `NUGEN_MODEL` from your Nugen account. Never commit `.env`.

Start the website:
```bash
python -m uvicorn server:app --reload
```
Open **http://127.0.0.1:8000/** (website) or **http://127.0.0.1:8000/docs** (try the API). Check Nugen at **http://127.0.0.1:8000/api/ai/status?ping=true**.

Local development without a key: set `NUGEN_REQUIRED=0` in `.env`. Built-in fallback text is then shown and labelled.

## 8. API routes
| Route | Purpose |
| :--- | :--- |
| `GET /api/health` | Server alive |
| `GET /api/ai/status` | Nugen status (`?ping=true` for a real test call) |
| `GET /api/weather?lat=&lon=` | Forecast, current conditions and source (live, cached, sample) |
| `POST /api/advice` | Full advice from the engine; `with_ai: true` adds Nugen's explanation |
| `POST /api/explain` | Nugen explanation of today's decision |
| `POST /api/summary` | Nugen weekly outlook |
| `POST /api/ask` | Same body plus `question` |
| `POST /api/share` | WhatsApp-style message |

Request body: `crop_id`, `soil_id`, `irrigation_method` (flood, sprinkler, drip), `area_value` (acres), `pump_hp`, `pump_discharge_lph`, `latitude`, `longitude`, `language` (en, mr, hi), `sowing_date`, and the optional farmer inputs `observed_rain_mm`, `soil_feel`, `sensor_moisture_pct`, `days_since_irrigation`, `crop_stress`, `mulch`, `power_slot`, `water_avail_factor`. Invalid input returns 422 with the field name.

## 10. Limitations
- Soil moisture comes from farmer input, not a satellite or a sensor network.
- Forecast rain may not arrive; re-run the advice daily.
- The savings baseline (25 mm every 3 days) and the confidence score are assumptions.
- Hindi and Marathi fallback text and crop tips need review by a fluent speaker or agronomist before a public demo.
